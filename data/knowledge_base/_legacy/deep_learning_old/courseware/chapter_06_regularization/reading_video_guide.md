# 第 6 章 正则化与泛化 阅读与视频学习指南

## 1. 本章推荐阅读顺序
1. 先阅读本章 main_note.md，标出不理解的概念。
2. 再查看 mind_map.mmd，把概念关系补成自己的图。
3. 完成 exercises.md 的基础题，再进入外部公开资料。
4. 若本章有 code_lab.md 或 interactive_animation.json，最后用实验或动画验证理解。

## 2. 外部资源学习目的
- Dive into Deep Learning：用于对照章节结构、公式和模型训练流程。
- PyTorch Tutorials：用于核对 API 使用、训练循环和实验组织。
- CS231n 或课程公开资料：用于理解视觉模型、训练诊断和项目报告思路。
- Speech and Language Processing：用于序列建模、注意力和语言任务背景。

## 3. 适合什么学生
适合已经完成本章主讲义阅读，但希望通过公开视频、官方文档或公开教材获得第二种解释方式的学生。若你连本章核心概念都无法说出，请先回到主讲义和题集，不要直接跳外部资料。

## 4. 观看/阅读前准备
准备一张纸记录三个问题：本章解决什么问题、关键变量是什么、实验中如何观察效果。阅读前先复述本章焦点：过拟合, 权重衰减, Dropout, BatchNorm, 数据增强。

## 5. 观看/阅读中关注点
关注讲解者如何定义问题、如何画模型结构、如何解释公式或代码。遇到代码时记录输入 shape、输出 shape、损失函数和优化器；遇到公式时记录变量语义和维度。

## 6. 暂停思考问题
- 这个资源解释的是本章哪个概念？
- 它和主讲义中的哪一节对应？
- 它给出的例子是否能转化为本系统的练习或实验？
- 如果我换一个数据集，哪些步骤保持不变，哪些需要调整？

## 7. 观看/阅读后任务
完成 3 件事：写 100 字复述；完成题集中至少 2 道相关题；把一个外部讲解中的例子改写成本章自己的学习笔记。若本章有代码实验，请运行一次并记录错误。
