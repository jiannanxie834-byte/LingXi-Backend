# 第 12 章 深度学习课程综合项目任务书

## 1. 项目背景
本综合项目要求学生把《深度学习》课程导学、表示学习、神经网络、端到端学习、数据驱动实验方法连接成一个完整作品。推荐主题为 CNN 图像分类项目，也可以在教师审核后选择序列分类、文本分类或小型生成模型。项目不追求模型堆砌，而是要求从问题定义、数据集、CNN baseline、训练验证、误差分析、消融实验和展示报告形成闭环。

## 2. 项目目标
1. 能清楚定义一个深度学习任务，说明输入、输出、评价指标和应用价值。
2. 能构建一个可复现的 baseline，例如 CNN 图像分类项目中的卷积层、池化层、分类头和训练循环。
3. 能记录训练验证过程，展示 loss、accuracy、混淆样本或错误样本分析。
4. 能完成至少一次消融实验，例如改变学习率、正则化、数据增强、模型宽度或训练轮数。
5. 能用指标表、图示和文字说明模型为什么有效、哪里失败、下一步如何改进。

## 3. 推荐任务拆解
### 3.1 问题定义
说明项目要解决什么问题，例如“对 32x32 彩色图片进行 10 类分类”。写明数据来源、样本规模、类别含义和潜在偏差。不得只写“训练一个模型”。

### 3.2 数据集与预处理
建立训练集、验证集和测试集。若使用公开数据，只保留原始链接和引用说明，不复制或重新分发第三方数据。需要记录输入 shape、归一化方式、标签编码、数据增强策略和异常样本处理方式。

### 3.3 CNN baseline
至少实现一个可运行 CNN baseline，包括 Conv2d、ReLU、Pooling 或 Global Average Pooling、Linear 分类层。若选择其他主题，也必须提供等价 baseline，例如 LSTM 序列分类或 Transformer Attention demo。

### 3.4 训练验证
报告训练命令、环境依赖、随机种子、epoch、batch size、学习率、优化器和损失函数。每轮至少记录训练 loss 和验证指标。出现过拟合时，需要解释训练/验证曲线差异。

### 3.5 消融实验
至少完成 2 组消融：一种改模型结构，一种改训练策略。示例：去掉 Dropout、替换 Adam/SGD、改变卷积通道数、加入或移除数据增强。消融必须用同一数据划分，不能只凭主观感受判断。

### 3.6 误差分析
挑选至少 8 个错误样本，说明错误原因可能来自类别相似、样本噪声、数据不均衡、模型容量不足或训练策略不合适。误差分析要反推改进方案。

## 4. 提交物
- 代码目录：包含训练脚本、模型定义、配置文件和 README。
- 项目报告：包含问题定义、数据说明、方法、实验结果、消融实验、误差分析和结论。
- 指标表：至少包含 baseline、改进模型、消融模型的训练/验证指标。
- 展示材料：可以是 PPT 大纲、流程图、关键代码注释或演示截图。
- 复现说明：写明运行命令、依赖版本、随机种子和输出文件位置。

## 5. 验收标准
1. 能在常规 CPU 环境下完成最小演示运行。
2. 代码能输出训练日志，报告能解释日志含义。
3. 指标表真实、完整，不允许只贴最优结果。
4. 消融实验有对照变量和结论。
5. 误差分析能提出下一步改进。
6. 项目报告与评分 Rubric 一一对应。

## 6. Rubric 摘要
- 问题定义与数据治理：20 分。
- 模型实现与训练验证：25 分。
- 实验设计、指标表和消融实验：25 分。
- 误差分析、复现说明和展示报告：20 分。
- 表达规范、引用合规和工程整洁度：10 分。

## 7. 版权与引用要求
外部数据、公开视频和参考代码只使用原始链接和学习说明，不下载、不搬运、不重新托管。报告中必须注明公开资料仅作结构参考，核心代码和分析由学生完成。
