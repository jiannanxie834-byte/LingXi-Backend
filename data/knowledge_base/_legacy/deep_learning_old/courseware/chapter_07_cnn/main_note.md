# 第 7 章 卷积神经网络 CNN

## 2. 本章在《深度学习》课程中的位置
本章属于核心章节。它连接前序章节的基础概念和后续章节的模型实践。围绕「卷积核、步幅填充、池化、经典网络、图像分类」建立主线后，学生应能说明这些概念如何影响模型表达能力、训练稳定性和项目落地。不要把本章当作孤立知识点记忆，而要把它放到数据、模型、损失、优化和评估的完整链条中理解。

## 4. 前置知识
学习本章前，需要具备 Python 基础、张量形状意识、训练集/验证集/测试集的基本概念，以及用损失函数衡量预测误差的直觉。若读到公式时卡住，不应立刻跳过，而要先判断公式里每个符号代表数据、参数、隐藏状态还是损失。若读到代码时卡住，优先检查张量 shape、batch 维、通道维、序列维和设备位置。

## 5. 核心概念一：卷积核
卷积核 是本章的入口概念。理解它时要问三个问题：它接收什么输入，产生什么输出，为什么这个输出对模型训练有帮助。很多学生只记定义，却没有把概念放进模型流程中。正确做法是把它放到一条链路里：数据进入模型，模型产生中间表示，损失函数给出反馈，优化器根据反馈更新参数。

## 6. 核心概念二：步幅填充
步幅填充 通常决定本章方法能否真正工作。它和 卷积核 的关系不是并列背诵，而是互相约束：如果前者定义了问题结构，后者往往决定计算方式或训练方式。学习时建议用一个小样本手算或画图，把输入、参数、输出、中间变量全部标出来。

## 7. 关键公式、机制或算法流程
卷积输出尺寸：H_out = floor((H + 2P - K)/S) + 1，宽度同理。
机制理解要遵循“符号含义 -> 维度检查 -> 计算顺序 -> 训练影响”的顺序。先判断每个变量代表一条样本、一个 batch、一个时间步还是一个参数矩阵，再判断公式是否能在形状上相乘或相加。许多错误并非公式不会，而是忽略了维度语义。

## 本章核心深化
CNN 的核心是利用图像局部性和平移共享。卷积核不是魔法滤镜，而是一组可学习参数，在空间位置上共享使用，从而显著减少全连接网络在图像上的参数规模。

学习 CNN 必须会计算输出尺寸，因为很多实际报错都来自卷积、池化、Flatten 之间的 shape 断裂。

## 8. 深度学习模型中的具体例子
例子一：在一次小型训练任务中，把本章概念用于解释 loss 曲线的变化。如果 loss 下降但验证集不提升，要回到本章概念判断是表达不足、优化不稳、过拟合还是数据处理问题。

例子二：把 卷积核 和 池化 放入同一张流程图，说明它们分别影响模型的哪一层。若它们改变的是输入表示，则重点检查数据预处理；若改变的是训练动态，则重点检查学习率、梯度或正则化。

例子三：用 5 个样本做一个最小实验，先写出预期现象，再运行代码验证。这能避免学生只看最终准确率而忽略机制。

## 9. 代码或伪代码示例
```python
model = nn.Sequential(nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2), nn.Flatten(), nn.Linear(16*16*16, 10))
```
代码阅读时不要只看函数名，要逐行标注张量形状和变量作用。若代码中出现 `.view`、`.reshape`、`.permute`、`transpose`、`backward`、`step` 等操作，必须说明它们改变的是数据布局、计算图还是参数值。

## 10. 常见误区与纠正
- 误区一：把「卷积神经网络 CNN」理解成孤立术语。纠正：把它放回数据、模型、损失、优化、评估链路。
- 误区二：只背公式，不检查维度。纠正：每次写公式都标出 batch、feature、channel 或 sequence length。
- 误区三：只看最后准确率。纠正：同时查看训练曲线、验证曲线和错误样本。
- 误区四：用复杂模型掩盖基础问题。纠正：先建立可解释 baseline，再逐步加入复杂结构。
