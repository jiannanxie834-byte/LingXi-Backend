### 题目 5：图像分类 的理解与应用

**题型**：代码理解题  
**对应知识点**：chapter_07_cnn / 图像分类  
**难度**：中等

**题目**：阅读下面伪代码，指出它要观察的现象，并说明如果输出 shape 或 loss 异常，应先检查哪里。

```python
for batch_x, batch_y in loader:
    logits = model(batch_x)
    loss = criterion(logits, batch_y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

**答案**：这段代码观察模型在「图像分类」相关设置下的训练闭环。若 shape 异常，先检查 batch_x、logits、batch_y 的维度；若 loss 异常，检查标签格式、学习率、模型输出和损失函数是否匹配。

**解析**：代码理解题不是背 API，而是确认数据、模型、损失和优化器之间是否对齐。

**常见错误**：只复述名词定义；没有说明输入输出；没有结合训练曲线或错误样本；把一次实验结果当作绝对结论。
