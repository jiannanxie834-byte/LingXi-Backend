# 第 7 章 卷积神经网络 CNN

## 一、学习定位与适用对象
卷积神经网络是深度学习处理图像、视觉特征和局部空间结构的重要模型。本章适合已经学过神经网络前向传播，但还不清楚卷积核、步幅、填充、特征图、局部连接和参数共享如何协同工作的学生。学习 CNN 不能只背网络名字，更要会计算输出尺寸、解释通道变化，并能用 PyTorch 写出最小卷积层示例。

## 二、本章在课程中的位置
CNN 位于神经网络基础之后、综合视觉项目之前。它把普通全连接网络对向量的处理扩展到图像网格。与全连接层相比，卷积层利用局部连接关注邻域，利用参数共享减少参数量，利用多通道卷积提取不同类型的空间特征。后续学习图像分类项目、目标检测、迁移学习和可视化动画时，都需要理解本章内容。

## 三、核心概念逐项讲解
卷积核是一个可学习的小矩阵或小张量，它在输入特征图上滑动，对局部区域做加权求和。步幅 stride 决定卷积核每次移动多少格，步幅越大，输出空间尺寸通常越小。填充 padding 是在输入边缘补零或补值，常用于保留边缘信息或控制输出尺寸。特征图 feature map 是卷积核在所有位置计算得到的响应图。局部连接意味着每个输出位置只看输入的一小块区域。参数共享意味着同一个卷积核在不同位置复用同一组参数，从而降低参数量并增强平移相关特征的捕捉能力。

## 四、输出尺寸计算
二维卷积常用输出尺寸公式为：`out = floor((in + 2 * padding - kernel_size) / stride) + 1`。其中 `in` 是输入高或宽，`padding` 是单侧填充大小，`kernel_size` 是卷积核尺寸，`stride` 是步幅。若输入为 `32x32`，卷积核为 `3x3`，padding 为 1，stride 为 1，则输出尺寸为 `floor((32 + 2 - 3) / 1) + 1 = 32`。这就是常说的 same convolution 效果。

## 五、具体例子
例子 1：灰度图输入通道为 1，使用 8 个 `3x3` 卷积核，输出通道数为 8。每个卷积核负责学习一种局部模式，如边缘、纹理或角点。

例子 2：RGB 图像输入 shape 为 `(batch, 3, 224, 224)`，如果卷积层为 `Conv2d(3, 16, kernel_size=3, stride=1, padding=1)`，输出 shape 为 `(batch, 16, 224, 224)`。空间尺寸保持不变，但通道数从 3 变为 16，说明模型学到了 16 组特征响应。

## 六、PyTorch Conv2d 示例
```python
import torch
import torch.nn as nn

x = torch.randn(4, 3, 32, 32)
conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, stride=1, padding=1)
y = conv(x)
print(y.shape)  # torch.Size([4, 16, 32, 32])
```
这段代码中，`in_channels=3` 对应 RGB 三通道，`out_channels=16` 表示使用 16 个卷积核，输出 16 张特征图。检查 shape 是学习 CNN 的第一习惯。

## 七、池化与感受野
池化层常用于降低空间尺寸和增强局部鲁棒性。最大池化保留局部区域最大响应，平均池化保留平均信息。感受野表示输出某个位置能够看到的输入区域范围。网络越深，感受野通常越大，模型能从边缘、纹理逐渐组合出更高层语义。

## 八、常见误区与纠正
误区一：把卷积核当成固定图片滤镜。纠正：卷积核参数是训练得到的，不是人工固定。
误区二：只看高和宽，忽略通道数。纠正：卷积核实际 shape 与输入通道数有关。
误区三：混淆 padding 和 stride。纠正：padding 增加边界，stride 改变滑动步长，两者都会影响输出尺寸。

## 九、自测题
1. 输入 `28x28`，卷积核 `5x5`，padding=0，stride=1，输出尺寸是多少？参考答案：24。
2. 为什么 CNN 参数量通常比全连接网络少？参考答案：局部连接和参数共享减少了需要学习的权重数量。
3. `Conv2d(3, 32, 3, padding=1)` 输入 `(8, 3, 64, 64)` 的输出 shape 是什么？参考答案：`(8, 32, 64, 64)`。

## 十、下一步学习建议
