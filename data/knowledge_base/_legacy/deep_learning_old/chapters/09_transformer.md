# 第 9 章 Attention 与 Transformer

## 一、学习定位与适用对象
Transformer 是现代深度学习中处理语言、图像、多模态和生成任务的重要架构。本章适合已经了解矩阵乘法、神经网络基础和序列建模，但对 Query、Key、Value、自注意力分数、多头注意力和位置编码仍感到抽象的学生。学习本章的目标不是背架构图，而是能说明每个 token 如何根据其他 token 聚合信息。

## 二、本章在课程中的位置
在 RNN/LSTM 之后学习 Transformer，可以更清楚地理解两类序列建模思路的差异。RNN 依靠时间步递归传递隐状态，Transformer 通过注意力机制并行建模 token 之间的关系。后续学习大模型、视觉 Transformer、跨模态检索和生成模型时，都离不开本章的自注意力机制。

## 三、Q/K/V 的含义
Query 表示当前位置想要查询什么信息，Key 表示每个位置能被匹配的特征，Value 表示被聚合的实际内容。对同一个输入表示 `X`，模型通过不同权重矩阵得到 `Q = XW_Q`、`K = XW_K`、`V = XW_V`。注意力不是直接比较原始 token，而是在可学习投影后的表示空间中计算相关性。

## 四、注意力分数与 Softmax
缩放点积注意力公式是 `Attention(Q,K,V)=softmax(QK^T/sqrt(d_k))V`。其中 `QK^T` 计算每个 Query 与所有 Key 的相似度，`sqrt(d_k)` 用于缩放，避免维度较大时点积值过大导致 softmax 过于尖锐。softmax 将分数转成权重，权重再与 Value 做加权求和，得到融合上下文的新表示。

## 五、多头注意力
单个注意力头只能在一个投影空间中学习关系，多头注意力把表示拆到多个子空间并行计算。一个头可能关注语法依赖，另一个头可能关注实体关系，还有一个头可能关注局部邻近信息。多个头的输出拼接后再线性变换，使模型获得更丰富的关系表达。

## 六、位置编码
自注意力本身不天然知道顺序，因为它同时比较所有 token。如果没有位置编码，“我喜欢深度学习”和“深度学习喜欢我”在集合意义上可能难以区分。位置编码把序列位置信息加入 token 表示，可以是固定正弦余弦编码，也可以是可学习位置向量。

## 七、具体例子
例子 1：句子“学生学习 CNN”中，token“学习”的 Query 可能会对“学生”和“CNN”的 Key 都产生较高分数，因为一个提供动作主体，一个提供学习对象。softmax 权重决定它从这两个位置各吸收多少信息。

例子 2：在图像 patch 序列中，一个 patch 可以通过自注意力关注远处但语义相关的 patch，这解释了 Transformer 相比局部卷积更容易建立长距离关系。

## 八、PyTorch 伪代码
```python
scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)
weights = torch.softmax(scores, dim=-1)
output = weights @ V
```
理解这三行比背整张 Transformer 架构图更重要。第一行算相关性，第二行归一化为权重，第三行根据权重聚合内容。

## 九、常见误区与纠正
误区一：把注意力权重当成绝对因果解释。纠正：权重能反映模型聚合信息的模式，但不能直接等同于人类解释。
误区二：忽略缩放因子。纠正：`sqrt(d_k)` 影响 softmax 稳定性，是训练稳定的重要细节。
误区三：认为 Transformer 完全不需要顺序。纠正：它需要位置编码或相对位置机制补充顺序信息。

## 十、自测题
1. Q、K、V 分别代表什么？参考答案：Query 表示查询，Key 表示匹配特征，Value 表示被聚合内容。
2. 为什么要除以 `sqrt(d_k)`？参考答案：避免维度大导致点积分数过大，使 softmax 更稳定。
3. 多头注意力相比单头有什么优势？参考答案：能在多个子空间并行学习不同关系。

## 十一、下一步学习建议
掌握自注意力后，可以继续学习 Transformer Encoder、Decoder、残差连接、LayerNorm 和前馈网络，再进入大模型、视觉 Transformer 或跨模态模型。实践上建议手写一次缩放点积注意力，并检查每一步张量 shape。
