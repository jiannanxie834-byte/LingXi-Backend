# 第 2 章 数学与机器学习前置知识

## 一、学习定位与适用对象
本章是《深度学习》课程的入口支架，服务于后续神经网络、反向传播、优化器、CNN、Transformer 和 PyTorch 实践。很多学生第一次接触深度学习时，会把主要困难归结为“模型太复杂”或“代码太长”，但真正卡住学习的常常是矩阵维度、梯度方向、损失函数和数据划分这些前置概念。本章适合数学基础一般、已经学过 Python 但还不能稳定解释模型训练过程的学生。

## 二、本章在课程中的位置
深度学习模型本质上由张量运算、可微函数和参数优化组成。线性层可以看作矩阵乘法加偏置，激活函数提供非线性，损失函数把预测误差变成可优化目标，梯度告诉参数应该向哪里调整。如果这些基础没有打牢，后续学习反向传播时会只背公式，学习 CNN 时会只看结构图，学习 Transformer 时会迷失在 Q/K/V 的维度变化里。

## 三、矩阵、向量与张量 shape
向量是一维数值序列，矩阵是二维数值表，张量是更高维的数据容器。在深度学习中，shape 表示数据每个维度的大小。例如一批 32 张 RGB 图片可以写成 `(32, 3, 224, 224)`，分别表示 batch size、通道数、高度和宽度。理解 shape 的关键不是记住某个固定顺序，而是能说明每个维度承载什么含义。矩阵乘法 `Y = XW + b` 中，若 `X` 的 shape 是 `(batch_size, input_dim)`，`W` 的 shape 应为 `(input_dim, output_dim)`，输出 `Y` 才能得到 `(batch_size, output_dim)`。

## 四、矩阵乘法在神经网络中的作用
神经网络的一层线性变换可以理解为把输入特征重新组合成新的特征。矩阵 `W` 的每一列对应一个输出神经元的权重，输入向量和该列做点积后得到一个激活前的值。矩阵乘法不是单纯的数学操作，而是模型“学习特征组合方式”的载体。训练过程会不断调整 `W` 和 `b`，让输出更接近真实标签。

## 五、函数、导数、梯度与链式法则
导数描述一维函数在某一点的变化率，梯度是多参数函数对每个参数的偏导数组合。损失函数 `L` 对参数 `w` 的梯度 `dL/dw` 表示：当 `w` 发生微小变化时，损失会如何变化。链式法则是反向传播的基础，例如若 `L = f(g(w))`，则 `dL/dw = dL/dg * dg/dw`。在神经网络中，每一层只需要计算本层局部梯度，再与后续传回来的梯度相乘，就能得到当前参数的更新方向。

## 六、损失函数与经验风险
损失函数衡量模型预测和真实答案之间的差距。分类任务常用交叉熵，回归任务常用均方误差。经验风险最小化的思想是：在训练集上让平均损失尽可能小，同时希望这种规律能泛化到未见过的数据。损失不是“错误个数”的简单统计，而是可微的优化目标，正因为它可微，梯度下降才有办法更新参数。

## 七、训练集、验证集和测试集
训练集用于拟合模型参数，验证集用于选择超参数和比较模型方案，测试集只在最终评估时使用。若用测试集反复调参，就等于把考试答案泄露给模型评估过程，最终准确率会失真。一个常见流程是：用训练集更新权重，用验证集决定学习率、网络结构和早停轮次，最后只用测试集报告一次最终效果。

## 八、例题与解析
例题 1：若输入 `X` 的 shape 为 `(16, 10)`，线性层希望输出 5 维表示，则权重 `W` 应为 `(10, 5)`，偏置 `b` 为 `(5,)`，输出 shape 为 `(16, 5)`。这里 16 是 batch size，不参与单个样本的特征维度计算。

例题 2：若某参数的梯度为 `+0.8`，学习率为 `0.01`，梯度下降更新为 `w_new = w - 0.01 * 0.8`。减号表示沿损失下降方向移动；若直接加梯度，通常会让损失增大。

## 九、常见误区
误区一：只会套矩阵乘法公式，不检查 shape 是否匹配。纠正方法是每次写公式时同时写出维度。
误区二：把验证集和测试集混用。纠正方法是把测试集锁起来，只在最后报告。
误区三：认为梯度越大越好。梯度过大可能导致训练震荡或梯度爆炸，需要学习率、归一化或梯度裁剪配合。

## 十、自测题
1. 输入 shape 为 `(64, 784)`，线性层输出 128 维，权重矩阵 shape 应是多少？参考答案：`(784, 128)`。
2. 为什么交叉熵损失适合分类任务？参考答案：它能衡量预测概率分布与真实类别之间的差距，并且可微，便于优化。
3. 如果学生用测试集选择最佳学习率，会有什么问题？参考答案：测试集信息泄露，最终评估不再客观。

## 十一、下一步学习建议
完成本章后，应进入“神经网络基础与感知机”，把矩阵乘法、偏置和激活函数连接成完整前向传播；随后再学习反向传播，理解链式法则如何在计算图中逐层传递梯度。
