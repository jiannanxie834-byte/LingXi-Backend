# 第 12 章 深度学习课程综合项目

## 1. 学习定位
课程综合项目用于检验学生能否把理论、代码、评估和表达整合起来。项目不是简单跑通代码，而是要形成可复现、可解释、可展示的学习成果。

## 2. 本章在课程中的位置
综合项目位于课程末端，要求学生根据前面章节选择 CNN、LSTM/GRU、Transformer 或生成模型相关任务，并完成数据准备、模型训练、误差分析和报告。

## 3. 学习目标
- 能定义项目问题、数据集、输入输出和评价指标。
- 能建立 baseline，并逐步改进。
- 能记录训练过程和误差案例。
- 能输出代码、实验报告、PPT 大纲和答辩材料。

## 4. 前置知识
需要掌握 PyTorch 训练循环、模型评估、训练曲线诊断，以及至少一种模型结构：CNN、LSTM/GRU 或 Transformer。

## 5. 项目一：CNN 图像分类
适合喜欢图解和代码的学生。任务包括选择小型图像数据集、实现 CNN baseline、加入数据增强、比较优化器或正则化策略，并用混淆矩阵分析错误类别。

## 6. 项目二：文本分类
适合希望理解 Transformer 或序列建模的学生。任务包括文本预处理、token 表示、模型选择、训练验证和错误样本分析。可从简化 RNN/GRU baseline 开始，再对比 Transformer Encoder。

## 7. 项目三：时间序列预测
适合学习 LSTM/GRU 的学生。任务包括构造滑动窗口、定义预测目标、训练序列模型、比较 MSE/MAE 等指标，并分析长期依赖带来的误差。

## 8. 项目流程
1. 明确问题和数据。
2. 建立 baseline。
3. 跑通训练与验证。
4. 记录训练曲线。
5. 做误差分析。
6. 设计改进实验。
7. 整理报告和演示。

## 9. 代码结构建议
```text
project/
  data/
  src/
    dataset.py
    model.py
    train.py
    evaluate.py
  outputs/
    checkpoints/
    figures/
  report.md
  README.md
```

## 10. 例子：图像分类训练入口
```python
# train.py 示例片段
for epoch in range(num_epochs):
    train_loss = train_one_epoch(model, train_loader, optimizer)
    val_acc = evaluate(model, val_loader)
    print(epoch, train_loss, val_acc)
```

## 11. 评分 Rubric
- 问题定义清晰：15 分。
- 数据处理合理：15 分。
- 模型和训练流程正确：25 分。
- 实验记录与误差分析：20 分。
- 报告和展示表达：15 分。
- 可复现性与代码规范：10 分。

## 12. 常见误区
- 没有 baseline，直接堆复杂模型。
- 只展示最高准确率，不分析错误样本。
- 训练集、验证集、测试集混用。
- README 不能让别人复现实验。
- PPT 只有结果，没有方法和反思。

## 13. 自测题与答案
1. 为什么项目必须有 baseline？
   答：baseline 提供参照，便于判断改进是否有效。
2. 错误样本分析有什么价值？
   答：能发现数据质量、类别混淆、模型偏差和后续改进方向。
3. 可复现项目至少需要记录什么？
   答：依赖版本、随机种子、数据划分、超参数、训练命令和模型保存方式。
