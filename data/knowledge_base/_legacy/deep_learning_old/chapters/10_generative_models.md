# 第 10 章 生成模型入门：自编码器、VAE、GAN 与扩散模型

## 1. 学习定位
生成模型关注“如何学习数据分布并产生新样本”。本章不追求训练大型图像模型，而是帮助学生理解不同生成范式的目标函数、训练机制和适用边界。

## 2. 本章在课程中的位置
本章建立在神经网络、损失函数、优化和概率分布基础上。它与判别式分类任务形成对照，也为理解现代多模态生成应用提供基础。

## 3. 学习目标
- 区分判别模型和生成模型。
- 解释自编码器、VAE、GAN、扩散模型的核心思想。
- 能说明各类生成模型的训练目标和常见风险。
- 能用一个小型 PyTorch 自编码器理解重构损失。

## 4. 前置知识
需要掌握 MLP、损失函数、概率分布、优化器、训练循环，以及基本张量操作。

## 5. 自编码器 AutoEncoder
自编码器由编码器和解码器组成。编码器把输入压缩成潜表示，解码器从潜表示重构输入。目标通常是最小化重构误差：

```text
L = ||x - decoder(encoder(x))||^2
```

自编码器能学习压缩表示，但普通自编码器不一定能稳定生成新样本。

## 6. VAE 变分自编码器
VAE 让潜变量服从概率分布，并加入 KL 散度约束，使潜空间更连续。它的核心是重参数化技巧，使采样过程可以参与反向传播。VAE 生成较稳定，但样本可能偏模糊。

## 7. GAN 生成对抗网络
GAN 包含生成器和判别器。生成器试图生成逼真样本，判别器试图区分真实样本和生成样本。二者形成 min-max 对抗：

```text
min_G max_D E[log D(x)] + E[log(1 - D(G(z)))]
```

GAN 的优点是样本锐利，缺点是训练不稳定、可能模式崩塌。

## 8. 扩散模型 Diffusion
扩散模型先逐步给数据加噪，再训练模型学习反向去噪。它常以噪声预测为目标，采样过程逐步从噪声恢复样本。扩散模型训练稳定、质量高，但采样成本较高。

## 9. 例子一：自编码器重构手写数字
输入是一张数字图片，编码器得到低维向量，解码器重构图片。若重构模糊，说明潜表示容量、网络结构或训练轮数不足。

## 10. 例子二：GAN 模式崩塌
如果生成器总生成非常相似的图片，即使判别器短期被骗过，也说明生成器没有覆盖完整数据分布。这是 GAN 的典型训练风险。

## 11. PyTorch 自编码器示例
```python
import torch
import torch.nn as nn

class AutoEncoder(nn.Module):
    def __init__(self):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(20, 8), nn.ReLU(), nn.Linear(8, 3))
        self.decoder = nn.Sequential(nn.Linear(3, 8), nn.ReLU(), nn.Linear(8, 20))
    def forward(self, x):
        z = self.encoder(x)
        return self.decoder(z)

x = torch.randn(16, 20)
model = AutoEncoder()
recon = model(x)
loss = nn.MSELoss()(recon, x)
print(float(loss))
```

## 12. 常见误区
- 把生成模型等同于“画图工具”。
- 混淆 AE、VAE、GAN、Diffusion 的训练目标。
- 只看生成样例，不关注数据分布、训练稳定性和评价指标。
- 忽略版权、数据来源和安全边界。

## 13. 自测题与答案
1. 普通自编码器为什么不一定适合随机采样生成？
   答：它没有强约束潜空间分布，随机点可能落在模型未学习的区域。
2. GAN 中判别器过强会怎样？
   答：生成器可能难以获得有效梯度，训练不稳定。
3. 扩散模型为什么采样慢？
   答：通常需要多步反向去噪，从纯噪声逐步恢复样本。
