# 1.1 算法、程序与问题规模

## 学习目标
理解算法、程序、输入输出和问题规模之间的关系，能用自然语言描述一个问题的处理步骤，并指出规模变量 n 代表什么。

## 核心讲解
算法是一组为解决问题而设计的有限步骤。它关注“先做什么、再做什么、什么时候停止”，不依赖某一种具体编程语言。程序是算法在某种语言和运行环境中的实现，会受到语法、库函数、机器性能等因素影响。学习数据结构与算法时，先要把真实问题抽象成输入、输出和约束条件，再讨论处理这些输入需要多少时间和空间。

问题规模 n 是描述输入大小的变量。数组问题中，n 常表示元素个数；字符串问题中，n 常表示字符长度；图问题中，可能同时使用顶点数 V 和边数 E。选对规模变量，是后续分析复杂度的前提。

## 简短例子
“在一组成绩中找最高分”的输入是一组数字，输出是最大值。算法可以是从第一个成绩开始记录当前最大值，再逐个比较。这里 n 就是成绩数量。

## 常见误区
不要把代码行数当成算法好坏的唯一标准；也不要把一次具体运行时间直接当成算法复杂度。复杂度分析关心的是输入规模变大时的增长趋势。

## 与后续学习的关系
本节帮助你建立问题抽象能力。后续学习数组、链表、树和图时，都要先明确输入规模，再选择合适的数据结构和算法。
