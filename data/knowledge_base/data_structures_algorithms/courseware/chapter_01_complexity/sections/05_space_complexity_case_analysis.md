# 1.5 空间复杂度与情况分析

## 学习目标
理解空间复杂度关注额外占用的存储空间，并能区分最好情况、最坏情况和平均情况的分析含义。

## 核心讲解
空间复杂度描述算法运行时额外需要多少存储空间。若算法只使用少量变量，不随输入规模增长，通常是 O(1)。如果需要复制一个长度为 n 的数组，额外空间就是 O(n)。递归算法还要考虑调用栈空间：递归深度为 n 时，栈空间通常是 O(n)。

情况分析用于描述不同输入下的表现。最好情况是最顺利的输入，例如线性查找第一个元素就命中；最坏情况是最不利的输入，例如目标不存在，需要扫描完整数组；平均情况关注大量输入下的期望表现。实际评价算法时，最坏情况常用于保证上限，平均情况用于估计日常表现。

## 简短例子
原地交换数组中两个元素只用一个临时变量，额外空间是 O(1)。如果为了反转数组而新建一个同样长度的数组，额外空间是 O(n)。

## 常见误区
不要把输入本身占用的空间算作额外空间；也不要忽略递归调用栈。分析最好、最坏情况时，要说清楚触发该情况的输入是什么。

## 与后续学习的关系
空间复杂度会影响算法在大数据量下能否运行。后续学习递归、树和图时，栈、队列、访问标记数组都会进入空间分析。
