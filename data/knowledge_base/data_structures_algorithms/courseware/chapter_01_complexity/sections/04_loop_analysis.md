# 1.4 循环结构复杂度分析

## 学习目标
能够分析单层循环、嵌套循环和规模每次减半的循环，知道如何根据循环变量变化估计执行次数。

## 核心讲解
分析循环时，关键不是看代码有几行，而是看核心语句会执行多少次。单层循环如果从 0 到 n - 1，每次加 1，通常执行 n 次，是 O(n)。双层循环若外层和内层都与 n 同阶，核心语句约执行 n² 次，是 O(n²)。如果循环变量每次乘 2 或除以 2，执行次数通常与 log n 成正比。

有些循环看起来复杂，但可以通过求和简化。例如内层从 0 到 i，外层 i 从 0 到 n - 1，总次数是 1 + 2 + ... + n，数量级是 n²，因此仍是 O(n²)。

## 简短例子
`i = 1; while i < n: i *= 2` 每次把 i 翻倍。i 需要经过 1、2、4、8 等值才能接近 n，因此循环次数约为 log₂n。

## 常见误区
不要看到 while 就默认 O(n)，也不要看到两层循环就立刻写 O(n²)。必须结合循环变量的初值、变化方式和终止条件分析。

## 与后续学习的关系
循环分析会直接用于排序、双指针、滑动窗口和动态规划。掌握本节后，你能更准确地判断代码瓶颈。
