# 第 1 章 算法导论与复杂度分析：章节概述

## 本章学习定位
本章是《数据结构与算法》的入口，目标不是马上记住大量算法，而是建立一套判断算法成本的语言。只有先明确“问题是什么、输入规模如何变化、程序要付出多少时间和空间”，后面学习数组、链表、树、图和动态规划时，才知道为什么同一问题会有不同方案。

## 本章学习目标
学完本章后，你应能区分算法和程序，能为常见问题选择合适的问题规模 n；能用大 O 表示法描述时间增长趋势；能识别常见复杂度等级；能分析简单循环、空间占用、最好/最坏情况；能用线性查找、二分查找和简单递归说明自己的复杂度判断过程。

## 推荐学习顺序
建议先读 1.1 建立问题抽象，再学习 1.2 和 1.3，掌握时间复杂度与增长等级；随后进入 1.4 和 1.5，练习从代码结构判断时间与空间；最后用 1.6 的查找与递归案例做综合检验。

## 本章资源使用建议
章节概述用于确定学习路线；小节正文用于理解概念边界；思维导图用于复习结构；练习题用于检查误区；代码任务用于把复杂度分析落到 Python 片段；视频指南只提供观看策略和待补充的公开资源入口。

## 与第 2 章的衔接
第 2 章会进入数组、链表、栈与队列。届时你需要用本章的方法判断访问、插入、删除、遍历等操作的时间与空间成本，因此本章是后续所有数据结构选择的评价基础。
