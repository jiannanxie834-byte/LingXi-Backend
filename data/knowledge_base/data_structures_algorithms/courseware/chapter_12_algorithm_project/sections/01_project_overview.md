# 12.1 综合项目的目标与选题方式

## 学习目标
理解综合项目的价值，能从算法可视化、迷宫寻路和刷题训练系统三个方向中选择适合自己的题目。

## 核心讲解
综合项目的目标不是再背一遍前面章节，而是把数据结构、算法复杂度、代码实现和结果表达放到同一个任务中。选题时应先判断自己想展示哪类能力：如果希望把排序、查找、栈队列、图遍历等过程讲清楚，可以选择算法可视化小系统；如果想练习建模和路径搜索，可以选择迷宫寻路与路径规划；如果更关注学习反馈和题目组织，可以选择简易刷题训练系统。好的选题需要有明确输入、可验证输出、核心算法和最小可运行版本，不宜一开始追求功能过多。

## 简短例子
如果选择迷宫寻路，输入可以是二维网格，输出是从起点到终点的一条路径；如果选择刷题系统，输入可以是题目答案和学生提交，输出是判分结果与错因记录。

## 常见误区
常见问题是题目过大，最后只有界面没有算法；或者只实现算法函数，没有说明使用场景和测试样例。

## 与课程能力的关系
本节把课程知识转化为项目目标，为后续实现、测试、报告和展示建立边界。清晰选题能减少返工，也能让教师更容易判断项目是否真正体现算法能力。
