# 12.5 项目报告与代码提交规范

## 学习目标
掌握综合项目报告结构、代码目录组织、README 编写、实验结果记录和提交规范。

## 核心讲解
项目提交物应让他人能够理解、运行和评价。代码目录建议包含入口文件、算法模块、数据样例、测试文件和文档目录。README 至少说明项目目标、运行环境、启动命令、输入输出示例和主要功能。报告应先说明问题建模，再说明使用了哪些数据结构与算法，接着展示系统功能、核心代码、测试样例、运行结果、遇到的问题和改进方向。实验结果不能只放截图，还要解释样例覆盖了哪些情况，例如正常输入、边界输入、无解情况和错误输入。

## 简短例子
迷宫项目可以提交 `maze.py`、`test_cases.json`、`README.md` 和项目报告。报告中展示一组可达迷宫、一组不可达迷宫，以及路径长度和访问节点数。

## 常见误区
常见问题是代码能在自己电脑运行，但缺少依赖说明；或者报告只描述界面，没有说明算法选择和测试依据。

## 与课程能力的关系
本节训练工程表达和可复现意识，让算法项目不仅能运行，还能被检查、复用和评价。
