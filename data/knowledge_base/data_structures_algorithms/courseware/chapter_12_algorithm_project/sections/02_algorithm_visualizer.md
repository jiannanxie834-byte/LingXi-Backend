# 12.2 项目一：算法可视化小系统

## 学习目标
明确算法可视化项目的目标、输入输出和交互方式，能选择适合展示的算法过程。

## 核心讲解
算法可视化小系统适合展示“过程明显、状态变化清楚”的算法，例如冒泡排序、插入排序、二分查找、栈操作、队列操作、BFS 遍历或最短路径搜索。项目输入可以是一组数组元素、一个查找目标或一张简化图；输出不只是最终结果，还应包含关键步骤，例如当前比较的元素、交换位置、访问节点、队列内容或已确定路径。交互设计要服务于理解，可以提供开始、暂停、单步执行、重置和速度调节。实现时应把算法逻辑和展示状态分开，先保证算法正确，再把每一步状态记录为可展示的数据。

## 简短例子
排序可视化中，每一步可以记录数组、正在比较的下标和是否发生交换。前端或控制台展示只读取这些步骤，不直接修改算法核心逻辑。

## 常见误区
常见错误是把颜色、按钮和动画效果当成项目主体，却没有记录算法状态；或者把展示逻辑写进算法循环，导致难以测试。

## 与课程能力的关系
本项目训练算法过程追踪、状态抽象和人机交互表达能力，适合帮助学生把“会写代码”提升为“能解释算法”。
