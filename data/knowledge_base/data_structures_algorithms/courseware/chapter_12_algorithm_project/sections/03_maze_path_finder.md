# 12.3 项目二：迷宫寻路与路径规划

## 学习目标
能把迷宫网格抽象成图问题，使用 BFS、DFS 或最短路径思想完成从起点到终点的路径搜索。

## 核心讲解
迷宫寻路项目的关键是建模。二维网格中的每个可通行格子可以看作图中的节点，上下左右相邻的可通行格子之间存在边，墙或障碍物不能通过。若所有移动代价相同，BFS 可以找到步数最少的路径；DFS 更适合展示搜索和回溯过程，但不保证最短。项目应定义清楚输入格式，例如 0 表示通路、1 表示障碍，同时指定起点和终点。输出可以是路径坐标列表、路径长度、访问顺序和无法到达的提示。实现时要保存前驱节点，才能从终点反推出完整路径。

## 简短例子
在一个 5×5 网格中，从左上角到右下角搜索。BFS 每次从队列取出一个格子，访问未访问的相邻格子，并记录它们来自哪个前驱格。

## 常见误区
常见错误是只判断能否到达，没有恢复路径；或者没有标记访问状态，导致重复入队甚至循环。

## 与课程能力的关系
本项目综合图建模、队列、搜索策略和边界条件处理，是把图算法用于实际路径规划的基础训练。完成后，学生应能把同样的建模方式迁移到地图搜索、任务调度和状态空间搜索等问题中。
