# 数据结构与算法综合项目报告模板

## 1. 项目名称
填写项目名称、选题方向和小组成员信息。

## 2. 项目目标
说明项目要解决的问题、使用场景和最终希望达到的效果。

## 3. 问题建模
描述输入、输出、约束条件和需要抽象出的数据结构或状态。

## 4. 使用的数据结构与算法
列出核心数据结构和算法，并说明选择原因、适用条件和复杂度。

## 5. 系统功能设计
说明功能模块、操作流程、数据流向和用户可以完成的任务。

## 6. 核心代码说明
粘贴关键函数或伪代码，解释主要变量、控制流程和边界处理。

## 7. 测试样例与运行结果
列出测试输入、预期输出、实际输出和结果分析，至少包含正常和边界样例。

## 8. 问题与调试过程
记录实现中遇到的问题、定位方法、修复过程和仍然存在的限制。

## 9. 项目总结与改进方向
总结收获，说明项目不足，并提出可以继续优化的功能或算法方向。
