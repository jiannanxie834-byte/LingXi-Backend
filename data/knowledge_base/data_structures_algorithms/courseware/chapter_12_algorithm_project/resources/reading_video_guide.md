# 第 12 章阅读与视频学习指南

## 如何完成本章项目
先确定项目方向，再写清输入、输出和验收标准。不要一开始追求复杂界面，应先保证核心算法可运行、结果可验证。

## 项目前准备
复习项目会用到的数据结构和算法，准备两到三组最小样例。迷宫项目需要准备网格样例，刷题系统需要准备题目数据，可视化项目需要准备可展示的步骤记录。

## 视频学习建议
视频适合补充开发流程和演示思路。观看时重点关注项目如何拆分模块、如何组织样例、如何展示结果，而不是照搬完整代码。

## 开发过程关注点
每完成一个功能就运行一次样例。核心算法、输入解析、结果展示和测试数据应尽量分开，方便定位错误。

## 完成后检查任务
检查 README 是否能让别人运行项目，报告是否说明算法选择，测试是否覆盖边界情况，展示材料是否能讲清项目价值。
