# 6.3 二叉树遍历：前序、中序与后序

## 学习目标
理解前序、中序和后序遍历的访问顺序，能用递归思想描述“根、左、右”三部分的处理关系。

## 核心讲解
遍历是按某种规则访问树中所有节点。前序遍历先访问根节点，再访问左子树和右子树，顺序可记为“根、左、右”；中序遍历先访问左子树，再访问根节点，最后访问右子树；后序遍历先访问左右子树，最后访问根节点。三种遍历都体现递归思想：处理一棵树时，先明确根节点何时被访问，再把同样规则应用到左子树和右子树。

## 简短例子
如果根为 A，左孩子为 B，右孩子为 C，那么前序结果是 A、B、C，中序结果是 B、A、C，后序结果是 B、C、A。更大树也按同样规则递归展开。

## 常见误区
不要只背结果顺序而不理解递归边界。空节点不输出，但它决定递归何时停止。另一个误区是把中序遍历误认为所有二叉树都会得到有序结果，只有二叉搜索树才有这种性质。

## 与后续学习的关系
深度优先遍历是树题最基础的代码框架。后续求高度、统计节点、判断结构性质和处理搜索树时，都会在遍历顺序上加入不同的计算逻辑。建议先手写访问序列，再写递归函数，避免把输出顺序和调用顺序混在一起。
