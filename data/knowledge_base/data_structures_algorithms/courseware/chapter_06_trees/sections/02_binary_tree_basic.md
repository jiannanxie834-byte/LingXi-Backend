# 6.2 二叉树的基本概念

## 学习目标
掌握二叉树的定义，能区分左子树、右子树、满二叉树和完全二叉树等基本概念。

## 核心讲解
二叉树是一类特殊的树结构，每个节点最多有两个孩子，通常称为左孩子和右孩子。左、右位置是结构的一部分，即使只有一个孩子，也要明确它是左孩子还是右孩子。满二叉树强调每一层节点都填满；完全二叉树强调除最后一层外都填满，最后一层从左到右连续排列。二叉树常用于表达递归结构，因为每棵二叉树都可以看成根节点、左子树和右子树三部分。

## 简短例子
一个表达式树可以用根节点保存运算符，左右子树保存参与运算的表达式。这样复杂表达式就能分解成更小的左右子问题。

## 常见误区
常见错误是认为二叉树必须每个节点都有两个孩子。实际上“最多两个”才是关键；空子树也是结构的一部分。另一个误区是把完全二叉树和满二叉树混为一谈。

## 与后续学习的关系
二叉树是前序、中序、后序遍历和二叉搜索树的基础。先理解左右子树的结构含义，后续才能正确写出递归访问顺序和查找路径。学习本节时可以把每个节点都看成一棵更小二叉树的根，这会让后面的递归代码更自然。
