# 5.5 优先队列的操作模型

## 学习目标
理解优先队列与普通队列的差异，能说明插入元素、查看最值和取出最值这几类操作的含义。

## 核心讲解
普通队列强调先进先出，而优先队列强调“优先级最高的元素先被处理”。优先级可以是数值大小、任务紧急程度、距离估计或自定义比较规则。堆常用来实现优先队列，因为堆顶能保存当前最小或最大元素，插入和取出后只需局部调整即可恢复结构。优先队列关注的是动态集合中的最值维护：元素会不断进入，也会不断按优先级离开。

## 简短例子
医院分诊系统中，患者不一定按到达时间处理，危急程度更高者需要更早被取出。把危急程度作为优先级，就能用优先队列描述这个过程。

## 常见误区
不要把优先队列等同于排序结果。它只保证每次取出的元素是当前最高优先级，并不要求内部所有元素都排好序。另一个误区是只用数组反复排序，这会造成不必要的开销。

## 与后续学习的关系
优先队列会在最短路径、任务调度、事件模拟和 Top-K 问题中反复出现。后续学习图算法时，能否理解优先队列会直接影响对 Dijkstra 等算法的掌握。
