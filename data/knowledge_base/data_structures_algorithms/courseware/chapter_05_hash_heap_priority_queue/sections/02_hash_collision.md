# 5.2 哈希冲突与解决方法

## 学习目标
理解哈希冲突的含义，知道链地址法和开放寻址法的基本思路，并能解释冲突为什么会影响性能。

## 核心讲解
哈希冲突指不同键经过哈希函数计算后落到同一个桶或位置。冲突无法完全避免，因为可能的键空间通常远大于表容量。链地址法是在同一个桶中维护一个链表或其他容器，把冲突元素挂在一起；开放寻址法则在当前位置被占用时，根据探测规则寻找下一个可用位置。冲突过多会让原本接近直接定位的查询变成在局部范围内继续查找，从而降低效率。

## 简短例子
若表容量为 10，两个键的哈希值取模后都等于 3，它们就会争用同一个位置。链地址法会把它们放入 3 号桶的同一条链中，查询时先定位桶，再在桶内比较真实键。

## 常见误区
不要认为“换一个哈希函数就没有冲突”。好的哈希函数只能减少集中冲突，不能从原理上消灭冲突。也不要只存哈希值而不比较原键，否则可能把不同键误判为同一个键。

## 与后续学习的关系
理解冲突后，使用 Set、Map 时就能明白为什么平均很快但最坏情况可能变慢，也能为后续分析装载因子、扩容和工程实现打基础。
