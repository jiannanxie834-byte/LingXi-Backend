# 5.3 Set 与 Map 的典型使用

## 学习目标
掌握 Set 和 Map 的常见用途，能在去重、计数、快速查找和索引映射场景中选择合适结构。

## 核心讲解
Set 表示不重复元素的集合，适合判断某个值是否出现、去除重复项或维护访问状态。Map 保存键到值的映射，适合统计次数、记录位置、建立编号到对象的索引。它们的使用重点不是背接口名称，而是识别问题中有没有“唯一性判断”或“从一个键快速找到相关信息”的需求。许多题目看似需要双重循环，实际可以用 Set 或 Map 把内层查找降到平均常数级。

## 简短例子
统计一段文本中每个单词出现次数时，可以用单词作为 Map 的键，用出现次数作为值。每读到一个单词，就把对应计数加一。

## 常见误区
常见错误是把 Set 和 Map 混用：只关心是否存在时用 Set 更直接；需要保存附加信息时才使用 Map。另一个误区是忘记键必须能稳定比较和哈希。

## 与后续学习的关系
Set 与 Map 是后续图遍历、动态规划记忆化、字符串处理和缓存设计中的基础工具。本节建立应用判断能力，为复杂问题中的状态记录做准备。
