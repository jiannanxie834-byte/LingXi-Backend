# 5.4 堆的基本结构与性质

## 学习目标
理解堆是一种满足堆序性质的完全二叉树，能区分最大堆和最小堆，并掌握父子节点下标关系。

## 核心讲解
堆通常用数组表示一棵完全二叉树。完全二叉树要求除最后一层外都填满，最后一层从左到右填充，因此可以不用显式指针也能定位父子关系。最小堆要求每个父节点的值不大于子节点，堆顶是全局最小值；最大堆则相反，堆顶是全局最大值。堆只保证父子之间的局部顺序，不保证整棵树从左到右完全有序。

## 简短例子
在 0 下标数组中，位置 i 的左孩子通常是 2i + 1，右孩子是 2i + 2，父节点是 (i - 1) // 2。插入新元素后，需要沿父节点方向调整以恢复堆序。

## 常见误区
不要把堆当成有序数组。堆只能快速访问堆顶元素，无法保证任意两个非父子节点的大小关系。另一个误区是忽略完全二叉树结构，导致数组下标关系写错。

## 与后续学习的关系
堆是实现优先队列的重要基础。理解堆结构后，才能进一步分析插入、取出最值和维护 Top-K 时为什么通常只需要对树高级别的路径进行调整。
