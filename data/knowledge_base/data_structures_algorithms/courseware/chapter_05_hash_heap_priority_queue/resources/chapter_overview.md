# 第 5 章 哈希表、堆与优先队列：章节概述

## 本章学习定位
第 5 章关注两类常用数据组织方式：一类用于快速定位信息，代表是哈希表以及由它支撑的 Set、Map；另一类用于动态维护最值，代表是堆和优先队列。本章的学习重点不是记住某个库函数名称，而是理解为什么换一种结构后，查找、计数、取最值这类操作会明显变快。

## 本章学习目标
学完本章后，应能解释哈希表平均 O(1) 查询的来源，理解冲突对性能的影响，能在去重、计数和索引映射中选择 Set 或 Map；同时能说清堆的完全二叉树结构、最小堆和最大堆的区别，并能用优先队列处理动态最值和 Top-K 问题。

## 推荐学习顺序
建议先学习哈希表基本思想，再学习冲突处理；随后转向 Set 与 Map 的应用场景。之后学习堆的结构性质，再理解优先队列的操作模型，最后用 Top-K 问题完成综合串联。

## 本章资源使用建议
阅读小节时请把“结构特征”和“适合操作”对应起来：哈希表对应快速查找，Set 对应去重，Map 对应映射和计数，堆对应快速访问最值，优先队列对应按优先级处理任务。练习题用于检查概念选择，代码任务用于落实 Python dict、set 和 heapq 的基本使用。

## 与第 4 章和第 6 章的衔接
第 4 章通过排序与二分展示了有序性带来的效率提升；本章进一步展示哈希和堆如何通过不同结构优化常见操作。第 6 章将进入树与搜索树，继续讨论层次结构、父子关系和有序维护。
