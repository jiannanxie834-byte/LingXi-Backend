# 2.5 队列与双端队列：先进先出与双端操作

## 学习目标
理解队列的 FIFO 特性、入队和出队操作，知道循环队列为什么能复用空间，并认识双端队列支持两端操作的特点。

## 核心讲解
队列也是受限线性结构，但它遵循先进先出：新元素从队尾进入，旧元素从队首离开。排队买票就是典型模型。队列常用于按到达顺序处理任务，例如广度优先搜索中的待访问节点。

用数组实现队列时，如果每次出队都移动后续元素，代价会很高。循环队列通过头尾指针在固定数组中循环移动，让已经空出的空间重新被使用。双端队列进一步放宽规则，允许在两端插入和删除，适合需要从两端维护候选元素的场景。

## 简短例子
打印任务按提交顺序进入队列，打印机从队首取任务执行；滑动窗口中维护候选最大值时，常会用双端队列保存有用元素。

## 常见误区
不要把队列和栈混淆。栈处理最近进入的元素，队列处理最早等待的元素；循环队列也不是把元素真的排成圆形，而是下标循环复用。

## 与后续学习的关系
队列是广度优先搜索和层序遍历的基础，双端队列会连接到滑动窗口、单调结构和更高效的区间维护方法。
