# 2.1 线性结构概述

## 学习目标
理解线性结构的基本特征，知道数组、链表、栈和队列为什么都可以归入线性结构，并能从“元素之间的前后关系”角度描述它们。

## 核心讲解
线性结构强调元素按一条顺序关系组织：除第一个和最后一个元素外，大多数元素都有直接前驱和直接后继。这里的“线性”不是说存储空间一定连续，而是说逻辑关系像一条线。数组通过下标表达顺序，链表通过节点指针连接顺序，栈和队列则在顺序关系上进一步限制操作入口。

学习线性结构时，要分清逻辑结构和存储结构。逻辑上都是一列元素，但实现方式不同，会带来访问、插入、删除和空间开销的差异。本章先建立整体视角，再分别学习几种常见结构的操作模型。

## 简短例子
一排学生按座位顺序排好，可以看成线性结构。你能说出每个人前后是谁，但不一定要求他们在内存中连续摆放。

## 常见误区
不要把线性结构等同于数组。数组只是线性结构的一种实现形式，链表、栈、队列同样体现元素之间的一对一前后关系。

## 与后续学习的关系
线性结构是递归、排序、图遍历等内容的基础。后面学习树和图时，也常会用栈或队列保存待处理节点。
