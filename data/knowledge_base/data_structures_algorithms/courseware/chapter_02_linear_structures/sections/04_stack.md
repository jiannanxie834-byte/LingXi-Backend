# 2.4 栈：后进先出的操作模型

## 学习目标
理解栈的 LIFO 特性，掌握 push、pop、peek 三类基本操作，并能识别括号匹配、函数调用和撤销操作中的栈模型。

## 核心讲解
栈是一种受限的线性结构，只允许在同一端进行插入和删除。新元素压入栈顶，删除时也从栈顶弹出，所以最后进入的元素最先离开，这就是后进先出。栈既可以用数组实现，也可以用链表实现，关键不在底层存储，而在操作规则。

常见操作包括 push 入栈、pop 出栈、peek 查看栈顶。使用栈时要注意空栈情况：空栈上继续 pop 或 peek 会产生错误。栈适合处理“最近的内容最先被解决”的问题，例如括号匹配中最近打开的左括号，需要最先与右括号配对。

## 简短例子
浏览器后退记录可以看成栈：最新访问的页面在栈顶，点击后退时先回到最近的上一页。

## 常见误区
不要把栈理解成普通列表。列表可以在多个位置操作，而栈强调受限入口；也不要忽略空栈和栈顶元素是否匹配。

## 与后续学习的关系
栈会在递归调用、深度优先搜索、表达式求值和单调栈中继续出现，是理解“局部状态保存”的重要工具。
