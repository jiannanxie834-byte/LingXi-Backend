# 第 2 章 数组、链表、栈与队列：章节概述

## 本章学习定位
本章进入数据结构课程的第一个核心板块：线性结构。它不急于追求复杂题型，而是帮助你建立“元素如何排列、如何访问、如何插入删除、操作规则如何限制使用方式”的基本判断能力。数组、链表、栈和队列看起来形式不同，但都围绕一列元素展开，是后续排序、递归、树图遍历和动态规划的常用基础。

## 本章学习目标
学完本章后，应能区分逻辑结构和存储结构，说明数组随机访问快但中间修改代价高，说明链表通过节点连接换取更灵活的局部修改，掌握栈的后进先出和队列的先进先出，并能初步判断双指针、单调栈适合解决的线性结构问题。

## 推荐学习顺序
建议先学习线性结构概述，再学习数组和链表的对比，随后学习栈与队列这两种受限线性结构，最后把双指针和单调栈作为入门技巧认识。不要一开始就刷综合题，先把操作模型和复杂度说清楚。

## 本章资源使用建议
先读章节概述明确路线，再按小节阅读正文；遇到数组、链表、栈和队列时，主动画出操作前后的结构变化。练习题用于检查概念边界，代码任务用于把节点、栈顶和操作顺序落实到 Python 实现中。

## 与第 1 章和第 3 章的衔接
第 1 章提供复杂度分析工具，本章把这些工具用于具体结构。第 3 章学习递归、分治与回溯时，会反复用到链表节点、调用栈和线性扫描思想，因此本章是从复杂度分析走向算法设计的桥梁。
