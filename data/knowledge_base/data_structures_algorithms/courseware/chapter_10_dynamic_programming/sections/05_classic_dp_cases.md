# 10.5 经典案例：爬楼梯、背包与最长公共子序列

## 学习目标
通过爬楼梯、0/1 背包和最长公共子序列三个入门案例，理解不同 DP 问题如何围绕状态、转移和边界展开。

## 核心讲解
爬楼梯是一维 DP 的入门案例，状态通常表示到达某阶的方案数，转移来自前一阶和前两阶。0/1 背包关注在容量限制下选择物品获得最大价值，状态常与“前几个物品”和“当前容量”有关，转移比较选或不选当前物品。最长公共子序列关注两个序列前缀的匹配关系，状态通常是 dp[i][j]，表示两个前缀的最长公共子序列长度。三个案例展示了 DP 的共性：先定义状态，再找转移，最后处理初始化和遍历顺序。

## 简短例子
若两个字符相等，LCS 的当前状态可以来自左上角加一；若不相等，就比较去掉其中一个字符后的两个子问题结果。这个过程体现了前缀状态之间的关系。

## 常见误区
不要把经典案例当成互不相关的公式集合。爬楼梯、背包和 LCS 的数组维度不同，是因为状态描述的子问题不同。另一个误区是背包中混淆 0/1 选择和可重复选择。

## 与后续学习的关系
这些案例是动态规划题目的基本原型。掌握后可以继续扩展到路径 DP、区间 DP、字符串 DP 和更复杂的优化问题。做新题时不必急着寻找同款模板，可以先判断它更像“一维推进”“容量选择”还是“两个前缀比较”。
