# 10.4 初始化、遍历顺序与 DP 表

## 学习目标
掌握初始化、遍历顺序和 DP 表之间的关系，理解为什么顺序错误会导致结果错误。

## 核心讲解
初始化用于给最小子问题或边界状态赋值，例如爬楼梯中的 dp[0]、dp[1]，或二维表中的第一行、第一列。遍历顺序必须保证计算当前状态时，它依赖的状态已经算好。若 dp[i] 依赖 dp[i-1]，就应从小到大遍历；若一维背包中当前容量依赖上一轮结果，就可能需要倒序遍历容量，避免同一物品被重复使用。DP 表不只是存答案的数组，它也是依赖关系的可视化工具：每个格子从哪些格子来，决定了填表方向。

## 简短例子
在 0/1 背包的一维优化中，容量通常要从大到小遍历。若从小到大，当前物品刚更新出的状态可能又被同一轮继续使用，相当于把 0/1 背包误写成完全背包。

## 常见误区
常见错误包括边界初始化漏掉、数组长度少一位、遍历方向与转移依赖相反，以及二维压缩成一维后仍沿用原来的遍历顺序。

## 与后续学习的关系
本节把抽象方程落实为可执行代码。经典案例中的多数 bug 都发生在初始化和顺序上，因此后续做题时应先画出依赖箭头再写循环。表格不是形式主义，它能暴露哪些格子先算、哪些格子后算，以及边界从哪里开始。
