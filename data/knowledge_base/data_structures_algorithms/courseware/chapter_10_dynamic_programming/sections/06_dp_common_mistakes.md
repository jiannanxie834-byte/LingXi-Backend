# 10.6 动态规划常见错误与优化入门

## 学习目标
识别动态规划中的常见错误，如状态定义模糊、转移漏情况、初始化错误和遍历顺序错误，并初步理解滚动数组优化。

## 核心讲解
DP 的难点往往不在代码行数，而在每一步是否自洽。状态定义模糊会让转移公式失去依据；转移漏情况会让部分答案无法被考虑；初始化错误会把边界值传递到后续所有状态；遍历顺序错误会导致读取未计算状态或重复使用当前轮结果。优化方面，若当前状态只依赖上一行或少数历史状态，就可以考虑滚动数组，用较小空间保存必要信息。但优化应建立在二维或完整 DP 已经理解正确的基础上，不能为了省空间先破坏可读性。

## 简短例子
二维背包表如果每一行只依赖上一行，就有机会压缩成一维数组；但压缩后容量遍历方向会变得重要，方向错误会改变物品是否可重复使用。

## 常见误区
常见错误是还没写清完整状态就急着压缩空间，结果难以调试。另一个误区是看到数组越界才补边界，而不是从状态定义出发设计初始化。

## 与后续学习的关系
本节帮助形成 DP 调试清单。后续遇到复杂题时，可以按“状态、转移、初始化、顺序、优化”逐项检查，而不是盲目修改代码。先保证完整表正确，再考虑空间压缩，通常比一开始就追求短代码更稳。
