# 10.1 动态规划的基本思想

## 学习目标
理解动态规划适合解决具有重叠子问题和最优子结构的问题，知道它不是简单递归，而是系统地保存并复用子问题结果。

## 核心讲解
动态规划通常用于把大问题拆成若干可复用的小问题。当不同求解路径会反复计算同一类子问题时，就出现了重叠子问题；当原问题的最优解可以由子问题最优解组合得到时，就具有最优子结构。动态规划的核心不是“写一个递归函数”，而是明确子问题是什么、结果如何保存、后续如何复用。它可以从递归记忆化开始理解，也可以直接用表格自底向上填充。相比贪心，动态规划往往会比较多个候选选择，而不是一次固定某个局部最优。

## 简短例子
计算第 n 阶楼梯走法时，走到第 n 阶可以来自第 n-1 阶或第 n-2 阶。如果反复递归会重复计算大量中间楼层，保存每个楼层结果就能避免重复。

## 常见误区
不要把动态规划等同于所有递归。没有重叠子问题时，保存表格可能没有意义。另一个误区是只背题型，而不分析状态和转移关系。

## 与后续学习的关系
本节建立 DP 的整体视角。后续会分别学习状态定义、转移方程、初始化和遍历顺序，再通过经典案例把抽象思想落到代码中。学习时建议先判断“是否真的有重复子问题”，再决定是否使用 DP，而不是看到优化题就直接套表格。
