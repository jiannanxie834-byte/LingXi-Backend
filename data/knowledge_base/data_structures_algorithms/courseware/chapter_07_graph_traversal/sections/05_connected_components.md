# 7.5 连通分量与访问标记

## 学习目标
理解连通分量的含义，能说明 visited 数组为什么能避免重复访问，并能用搜索统计图中有多少个互不连通的部分。

## 核心讲解
在无向图中，如果一组顶点之间可以通过若干条边互相到达，它们就属于同一个连通分量。统计连通分量时，通常遍历所有顶点：如果某个顶点尚未访问，就从它出发做一次 BFS 或 DFS，把能到达的顶点全部标记；这一次搜索结束，就找到了一个分量。继续扫描未访问顶点，直到所有顶点都被处理。visited 的作用是记录某个顶点是否已经归入某次搜索结果，避免重复搜索和重复计数。

## 简短例子
班级同学按“互相认识”连边，若 A、B、C 互相可达，D、E 互相可达，但两组之间没有边，那么图中至少有两个连通分量。

## 常见误区
常见错误是每看到一个顶点就把计数加一，却没有先判断它是否已被之前搜索访问。另一个误区是在有向图中直接套用无向连通概念，忽略方向会改变可达关系。

## 与后续学习的关系
连通分量是图算法中的基本结构判断。后续学习最小生成树、拓扑排序和图的路径问题时，都会先关心图是否连通或哪些部分可达。
