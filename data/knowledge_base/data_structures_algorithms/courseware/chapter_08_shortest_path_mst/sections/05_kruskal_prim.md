# 8.5 Kruskal 与 Prim 算法

## 学习目标
理解 Kruskal 按边排序选边、Prim 从点集逐步扩展的基本思想，能说出二者的适用直觉。

## 核心讲解
Kruskal 从边的角度构造最小生成树：先把所有边按权重从小到大排序，再依次尝试选择边；如果这条边连接了两个尚未连通的部分，就加入结果，否则跳过以避免成环。Prim 从点集的角度出发：从任意起点开始，维护当前已连接点集，每次选择一条权重最小、能把新顶点接入点集的边。二者都利用贪心思想，但观察对象不同，一个看边，一个看当前已扩展的顶点集合。

## 简短例子
如果边列表容易排序，Kruskal 的思路很直观；如果从某个起点逐步扩张并能快速找到跨出当前集合的最小边，Prim 的思路更自然。

## 常见误区
不要认为只要边权小就一定能加入 MST，若加入后形成环，就必须跳过。也不要把 Prim 理解为普通最短路径，它关注的是连接新顶点的最小边。

## 与后续学习的关系
本节建立 MST 构造思路。下一节会专门说明并查集如何服务 Kruskal 的成环判断，使选边过程更高效。学习时可以用同一张图分别手推两种算法，观察它们选择边的出发点差异。
