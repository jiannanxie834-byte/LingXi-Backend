# 8.2 Dijkstra 算法：非负权图中的单源最短路径

## 学习目标
理解 Dijkstra 的贪心思想、dist 数组、松弛操作、优先队列优化和非负权限制。

## 核心讲解
Dijkstra 用于边权非负的单源最短路径问题。它维护 dist 数组，表示从起点到各顶点的当前最短已知距离；每次选出 dist 最小且尚未最终确定的顶点，再用它去尝试更新相邻顶点距离，这个更新过程称为松弛。若通过当前顶点到邻居的距离更短，就修改邻居的 dist。使用优先队列可以更快取出当前距离最小的候选顶点。算法正确性依赖非负权，因为一旦某个点以最小距离被取出，后续路径不会再通过负边把它变得更短。

## 简短例子
从 A 出发，若当前已知到 B 的距离是 5，到 C 的距离是 2，就优先处理 C；如果经过 C 到 B 的总距离为 4，就把 B 的 dist 从 5 松弛为 4。

## 常见误区
不要在存在负权边的图上直接使用 Dijkstra。另一个误区是只更新一次相邻点就结束，实际上优先队列中可能会不断出现更短候选。

## 与后续学习的关系
Dijkstra 是最短路径的核心算法之一，也会连接优先队列和图表示。理解松弛后，Bellman-Ford 与 Floyd-Warshall 的更新思想会更容易比较。
