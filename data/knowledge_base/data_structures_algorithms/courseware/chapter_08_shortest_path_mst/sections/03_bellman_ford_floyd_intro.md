# 8.3 Bellman-Ford 与 Floyd-Warshall 入门

## 学习目标
初步理解 Bellman-Ford 适合处理负权边，Floyd-Warshall 适合多源最短路径，并能与 Dijkstra 做适用条件对比。

## 核心讲解
Bellman-Ford 也是单源最短路径算法，它反复遍历所有边进行松弛，因此可以处理负权边，并能用于发现某些负权环问题。它通常比 Dijkstra 慢，但适用范围更宽。Floyd-Warshall 面向多源最短路径，核心想法是逐步允许更多中间点参与路径更新，最终得到任意两点之间的最短距离。本节只做入门比较：Dijkstra 适合非负权单源场景，Bellman-Ford 适合含负权边的单源场景，Floyd-Warshall 适合顶点规模不大但需要全点对结果的场景。

## 简短例子
若题目要求从一个起点出发，并且边权非负，Dijkstra 往往更合适；若存在负权边，就要考虑 Bellman-Ford；若需要任意两个城市之间的最短距离表，可以考虑 Floyd-Warshall。

## 常见误区
不要把三种算法当成互相替代的模板。它们面向的边权条件、起点数量和复杂度不同。另一个误区是把负权边和负权环混为一谈。

## 与后续学习的关系
本节帮助建立最短路径算法选择意识。后续遇到带权图题目时，先判断边权和查询类型，再决定算法，而不是只凭熟悉程度选择。
