# 8.1 最短路径问题与带权图

## 学习目标
理解带权图、路径长度、单源最短路径和多源最短路径的含义，能说明本章与 BFS、DFS 的关系。

## 核心讲解
带权图是在边上附加数值的图，权重可以表示距离、时间、费用或风险。路径长度通常是路径上所有边权之和。最短路径问题关注在带权图中找到代价最小的路径：如果从一个起点到所有其他顶点，称为单源最短路径；如果需要任意两点之间的最短路径，就属于多源最短路径。第 7 章的 BFS 可处理无权图中的最少边数问题，但当边的代价不同，仅按层扩展就不够，需要更专门的算法。

## 简短例子
在地图中，城市是顶点，道路是边，道路长度是权重。从城市 A 到城市 D 可能有多条路线，最短路径选择的是总距离最小的一条，而不是经过边数最少的一条。

## 常见误区
不要把“经过边数最少”和“权重总和最小”混为一谈。无权图中两者可能一致，带权图中则不一定。另一个误区是看到图搜索就直接套 BFS 或 DFS。

## 与后续学习的关系
本节只建立问题背景。后续会学习 Dijkstra、Bellman-Ford 和 Floyd-Warshall 的适用条件，也会进入最小生成树这一类不同目标的带权图问题。
