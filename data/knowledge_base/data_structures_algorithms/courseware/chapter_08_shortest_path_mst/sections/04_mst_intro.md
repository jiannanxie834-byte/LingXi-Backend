# 8.4 最小生成树问题

## 学习目标
理解最小生成树的定义，知道它适用于连通无向带权图，并能区分它和最短路径问题。

## 核心讲解
最小生成树要求在连通无向带权图中选择若干条边，使所有顶点都被连接起来，并且边权总和最小。生成树必须连接所有点，且不能形成环；如果有 n 个顶点，生成树通常包含 n - 1 条边。它与最短路径不同：最短路径关注两个点或一个起点到其他点的路径代价，最小生成树关注用最低总成本把所有点连成一个整体。它常用于网络铺设、道路连接和集群连接等“全体连通成本最小”的场景。

## 简短例子
要把多个校区用光纤连接起来，目标可能不是让任意两校区之间距离最短，而是用最小总长度让所有校区都能互相连通，这就是最小生成树的直觉。

## 常见误区
不要把 MST 当成从某个起点出发的最短路径树。两者目标不同，选出的边也可能不同。另一个误区是在有向图或不连通图上直接谈普通 MST。

## 与后续学习的关系
本节只明确问题定义。后续 Kruskal 和 Prim 会给出两种构造最小生成树的思路，并查集会帮助 Kruskal 快速判断选边是否成环。先把目标分清，后面算法步骤才不会和最短路径混在一起。
