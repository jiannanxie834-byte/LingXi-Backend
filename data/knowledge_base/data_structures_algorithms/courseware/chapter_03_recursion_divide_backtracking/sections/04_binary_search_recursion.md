# 3.4 递归版二分查找

## 学习目标
用递归版二分查找理解递归如何缩小问题规模，掌握左右边界、终止条件和复杂度分析的基本方法。

## 核心讲解
二分查找适用于有序数组。递归写法把“在区间 [left, right] 中查找目标值”作为当前问题。每次取中点 mid，如果 nums[mid] 等于目标值就返回；如果目标更小，就递归查左半区间；如果目标更大，就递归查右半区间。这样每次调用都会把搜索范围缩小约一半。

终止条件通常是 left > right，表示区间为空，目标不存在。分析复杂度时，问题规模从 n 变成 n/2，再变成 n/4，所以调用层数是 O(log n)。每层只做常数次比较，因此时间复杂度为 O(log n)，递归调用栈空间也是 O(log n)。

## 简短例子
在 [2, 5, 8, 12, 16] 中查找 12，先看中点 8，目标更大，于是只在右半区间 [12, 16] 中继续查找。

## 常见误区
不要忘记数组必须有序；也不要在更新边界时继续包含 mid，否则可能导致区间不缩小。递归出口要覆盖空区间。

## 与后续学习的关系
递归版二分查找让你看到递归、分治和复杂度分析如何结合。第 4 章学习二分查找和排序时会继续使用这些边界思想。
