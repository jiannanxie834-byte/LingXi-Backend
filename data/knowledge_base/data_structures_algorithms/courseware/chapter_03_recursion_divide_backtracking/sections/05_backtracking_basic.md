# 3.5 回溯思想：选择、探索与撤销

## 学习目标
理解回溯适合搜索所有可能方案的问题，掌握选择、探索、撤销三个动作，并能区分回溯和普通递归。

## 核心讲解
回溯可以看成带有“试探”的递归搜索。面对多个可能选择时，先选一个，把它加入当前路径；然后继续探索后续选择；探索结束后撤销这次选择，回到上一步尝试其他分支。这个过程像在搜索树中深度优先地走路，走不通或走完一条路径后退回来。

回溯的关键不是把所有循环和递归写在一起，而是明确当前路径表示什么、可选项有哪些、什么时候记录答案、什么时候撤销状态。它常用于排列、组合、子集、棋盘搜索等需要枚举方案的问题。

## 简短例子
从 {A, B, C} 中选两个字母组成组合，可以先选 A，再尝试 B、C；回到只选 A 之前，再从 B 开始尝试后续选择。

## 常见误区
不要忘记撤销状态，否则一个分支的选择会污染其他分支；也不要在基础阶段急着加入复杂剪枝，应先保证搜索过程正确。

## 与后续学习的关系
回溯会在图搜索、组合优化和约束满足问题中继续出现。理解它的状态管理，有助于后续学习更复杂的搜索算法和状态剪枝。
