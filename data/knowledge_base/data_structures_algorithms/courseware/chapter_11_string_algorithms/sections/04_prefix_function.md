# 11.4 前缀函数与 next 数组

## 学习目标
理解“最长相等前后缀”的含义，能说出前缀函数或 next 数组为什么能指导 KMP 回退。

## 核心讲解
前缀函数记录的是：对模式串的某个前缀来说，它的真前缀和真后缀中最长相等部分有多长。真前缀不能等于整个字符串，真后缀也不能等于整个字符串。例如 `abab` 的最长相等前后缀是 `ab`，长度为 2。next 数组在不同教材中定义略有差异，但核心作用相同：当比较失败时，告诉算法模式串应该回到哪个已知可用的位置。理解这个数组时，不要只盯着下标变化，而要问：当前已经匹配的片段里，哪一部分可以保留下来继续尝试。

## 简短例子
模式串 `ababaca` 中，前缀 `ababa` 的最长相等前后缀是 `aba`。如果失配发生在后面，算法可以利用这段重合关系，不必把模式串完全移回开头。

## 常见误区
常见错误是把“前缀”和“后缀”理解成任意子串，或把整个字符串也算进去。还有同学会背 next 表，却无法解释某个回退值从哪里来。

## 与后续学习的关系
前缀函数是 KMP 的预处理结果，也是理解字符串周期性和模式重复结构的入口。掌握它后，再看完整 KMP 代码会轻松很多。
