# 11.3 KMP 算法的核心思想

## 学习目标
理解 KMP 的核心目标：在失配时利用模式串内部结构，避免模式串从头开始比较。

## 核心讲解
KMP 关注的是“已经匹配过的前缀中，有多少信息还能继续使用”。当文本串和模式串比较到某一位发生失配时，暴力法会把模式串移动一格并从头比较；KMP 则根据模式串已经匹配的部分，找到一个仍可能成立的较短前缀，让模式串跳到合适位置继续比较。这样文本串指针通常不需要回退，每个字符被处理的次数受到控制。KMP 的难点不在比较动作本身，而在失配时应该让模式串回退到哪里。这个回退位置由前缀函数或 next 数组提供。

## 简短例子
如果模式串前几位已经匹配出 `abab`，下一位失配时，不必完全丢弃 `ab` 这段信息，因为它既是已匹配部分的前缀，也可能作为后续比较的起点。

## 常见误区
常见误区是把 KMP 记成一套复杂下标模板，而没有理解它为什么能跳过比较。另一个误区是认为 KMP 会“跳过文本字符”，实际上它主要是调整模式串的比较位置。

## 与后续学习的关系
本节只解释 KMP 的优化动机。下一节会单独说明前缀函数和 next 数组的含义，帮助把“应该回退到哪里”变成可计算的信息。
