# 11.6 滚动哈希入门

## 学习目标
理解滚动哈希的基本思想，知道它如何把字符串片段比较转化为哈希值比较，并认识哈希冲突风险。

## 核心讲解
滚动哈希会为字符串片段计算一个数值摘要。查找长度为 m 的模式串时，可以先计算模式串的哈希值，再依次计算文本串中每个长度为 m 的窗口哈希。窗口从左向右移动时，不必每次重新统计全部字符，而是移除左端字符的影响，加入右端新字符的影响，因此称为“滚动”。这种方法能快速筛选可能匹配的位置，但哈希值相同不一定代表字符串完全相同，因为不同字符串可能产生相同哈希值。入门阶段只需要掌握“用哈希快速比较片段”的思路，以及必要时再做原串校验。

## 简短例子
如果要在长文本中查找长度为 3 的模式串，可以依次比较每个长度为 3 的窗口哈希。哈希不同一定不匹配；哈希相同则需要进一步确认字符是否真的一致。

## 常见误区
常见误区是把哈希值相等当成绝对相等，忽略冲突。另一个误区是过早追求复杂公式，而没有先理解窗口、移除、加入和二次校验这四个动作。

## 与后续学习的关系
滚动哈希是字符串匹配的另一种思路，也能用于去重、片段比较和文本检索。本章只做入门，不展开复杂冲突处理和高级技巧。
