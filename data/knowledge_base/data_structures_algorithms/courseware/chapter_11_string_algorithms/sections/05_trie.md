# 11.5 Trie 字典树

## 学习目标
理解 Trie 的节点、边、插入和查询过程，能判断它适合处理哪些前缀相关问题。

## 核心讲解
Trie 又称前缀树，用一棵树保存一组字符串。树中的一条边通常表示一个字符，从根节点到某个节点的路径就对应一个前缀。插入单词时，从根开始按字符依次走；如果某条边不存在，就创建新节点；单词结束处通常要做结束标记。查询完整单词时，不仅要能沿路径走完所有字符，还要检查结束标记。前缀查询则只需要确认路径是否存在。Trie 的优势是把公共前缀共享起来，适合词典、自动补全、前缀统计等任务。

## 简短例子
插入 `to`、`tea`、`ten` 时，它们都以 `t` 开头，其中 `tea` 和 `ten` 又共享 `te` 前缀。Trie 会把这些公共路径合并，而不是为每个单词重复存储全部字符。

## 常见误区
常见错误是查询单词时只检查路径存在，忘记判断是否是完整单词。例如插入了 `tea`，路径 `te` 存在，但它未必是一个已插入单词。

## 与后续学习的关系
Trie 把字符串集合组织成树结构，和 KMP、哈希的定位思路不同。它为后续的词典检索、前缀匹配和字符串工程应用提供了基础。
