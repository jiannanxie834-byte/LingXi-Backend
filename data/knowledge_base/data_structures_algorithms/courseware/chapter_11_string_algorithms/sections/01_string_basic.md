# 11.1 字符串问题的基本概念

## 学习目标
理解字符串、子串、文本串、模式串和匹配位置这些基本术语，能把一个文字处理需求转化为清晰的算法问题。

## 核心讲解
字符串可以看作由字符按顺序组成的线性序列。讨论字符串算法时，通常把被查找的长字符串称为文本串，把想要查找的短字符串称为模式串。子串要求字符连续出现，子序列则只要求相对顺序不变，这两个概念很容易混淆。匹配位置指模式串在文本串中从哪个下标开始完整出现，例如在文本串 `ababc` 中查找模式串 `abc`，匹配位置是 2。字符串算法重要，是因为搜索、编辑器查找、敏感词过滤、拼写提示、基因序列分析和日志检索都离不开对字符序列的定位、比较和组织。

## 简短例子
文本串为 `banana`，模式串为 `ana` 时，模式串可以从下标 1 和 3 开始匹配。这里讨论的是连续片段，所以 `bnn` 不是子串。

## 常见误区
常见错误是把字符集合当成字符串，忽略顺序；或者把子串和子序列混为一谈。另一个误区是只关心是否出现，而不说明需要返回第一个位置、全部位置还是出现次数。

## 与后续学习的关系
本节提供统一术语。后面的暴力匹配、KMP、Trie 和滚动哈希都会围绕文本串、模式串、前缀、后缀和匹配位置展开。
