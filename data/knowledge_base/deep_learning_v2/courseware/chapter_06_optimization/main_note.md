## 1. Mini-batch

**来源位置**：batch 梯度下降法；标题层级包括 batch 梯度下降法、Mini-Batch 梯度下降法、batch 的不同大小（size）带来的影响、mini-batch 大小的选择、获得 mini-batch 的步骤、符号表示。

**重构讲解**：Mini-batch 将完整训练集切成若干小批量，每次只用一个 batch 计算梯度并更新参数。它解决的是 batch gradient descent 在大数据集上每一步过慢的问题，同时保留向量化计算效率。

**来源要点摘录**：
- ## batch 梯度下降法 **batch 梯度下降法**（批梯度下降法，我们之前一直使用的梯度下降法）是最常用的梯度下降形式，即同时处理整个训练集。
- 而处理的这些一小部分训练子集即称为 **mini-batch**。
- ## Mini-Batch 梯度下降法 **Mini-Batch 梯度下降法**（小批量梯度下降法）每次同时处理单个的 mini-batch，其他与 batch 梯度下降法一致。
- 使用 batch 梯度下降法，对整个训练集的一次遍历只能做一个梯度下降；而使用 Mini-Batch 梯度下降法，对整个训练集的一次遍历（称为一个 epoch）能做 mini-batch 个数个梯度下降。

**代码或实验落点**：
- 本节重点是概念、公式或结构理解；可在章节练习中补充最小实验。

**学习检查**：给定 m 个样本和 batch size，能算出 batch 数量，并解释为什么最后一个 batch 可能小于设定大小。

**常见误区**：把 Mini-batch 理解成随机丢弃数据，而不是分批使用全部训练样本。

## 3. Momentum

**来源位置**：课程综合材料。

**公式/结构线索**：`v_t = beta v_{t-1} + (1-beta) g_t`。

**重构讲解**：Momentum 为梯度更新引入指数加权平均，让参数更新带有惯性，减少震荡方向的来回摆动，加快一致下降方向的收敛。

**来源要点摘录**：
- 本节作为课程组织知识点，由课程地图、章节讲义和后续实验共同支撑。

**代码或实验落点**：
- 本节重点是概念、公式或结构理解；可在章节练习中补充最小实验。

**学习检查**：能解释 beta 接近 0 和接近 1 时，更新速度与平滑程度如何变化。

**常见误区**：把 Momentum 当成简单调大学习率，忽略它是在平滑梯度方向。

## 4. RMSProp

**来源位置**：课程综合材料。

**重构讲解**：RMSProp 对梯度平方做指数加权平均，并按维度缩放学习步长，使梯度较大的方向步子变小、梯度较小的方向保留有效更新。

**来源要点摘录**：
- 本节作为课程组织知识点，由课程地图、章节讲义和后续实验共同支撑。

**代码或实验落点**：

**学习检查**：能说明为什么 RMSProp 有助于处理不同参数维度梯度尺度差异。

**常见误区**：只记 RMSProp 名字，不知道它用梯度平方控制每个方向的有效步长。

## 5. Adam

**来源位置**：课程综合材料。

**公式/结构线索**：`theta_t = theta_{t-1} - alpha · m_hat / (sqrt(v_hat)+eps)`。

**重构讲解**：Adam 同时使用一阶矩估计和二阶矩估计，相当于把 Momentum 的方向平滑与 RMSProp 的尺度自适应结合起来，是常用的深度学习优化器。

**来源要点摘录**：
