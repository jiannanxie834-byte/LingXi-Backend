# 第 1 章 深度学习导论与课程学习诊断

## 章节定位

建立课程全局地图，完成基础诊断，明确从表示学习、神经网络到项目实践的学习路径。 本章整合参考来源：计算机视觉；经典卷积网络；batch 梯度下降法；数据划分：训练 / 验证 / 测试集；超参数调试处理；深层网络中的前向和反向传播；笔记；错误分析；非线性激活；线性层及其他层。课程讲义采用重新组织后的教材式表达，用于学生学习、RAG 检索和个性化资源生成。

## 易错点与纠偏

- 只关注结论，不记录实验条件，导致无法复现或比较。
- 把相关知识当作主标题，忽略用户当前真正要学的主题。
- 在没有证据的情况下推断学生水平，造成推荐过难或过浅。
- 忽略前置知识，使学习路线看似完整但执行困难。
