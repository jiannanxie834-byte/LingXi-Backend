# 第 4 章 前向传播、损失函数与反向传播

## 一、学习定位与适用对象
反向传播是深度学习课程中最关键的训练机制之一。本章适合已经理解神经元、线性层和激活函数，但仍然不清楚“模型如何从错误中学习”的学生。学习本章时，不应只背 `loss.backward()`，而要能解释前向传播、损失函数、梯度、链式法则和参数更新之间的关系。

## 二、本章在课程中的位置
前向传播负责把输入数据逐层变成预测结果，损失函数负责把预测结果和真实标签之间的差距量化，反向传播负责计算损失对每个参数的梯度，优化器再根据梯度更新参数。本章连接了神经网络结构和优化算法，是学习 SGD、Adam、CNN 训练、Transformer 训练和 PyTorch 工程实践的基础。

## 三、核心概念逐项讲解
前向传播是从输入到输出的计算过程。例如输入图片经过卷积层、激活函数、池化层和分类头后得到类别概率。损失函数是训练目标的数值化表达，分类任务常用交叉熵，回归任务常用均方误差。梯度表示损失对参数变化的敏感程度，梯度方向告诉我们参数应该往哪里调。链式法则说明复合函数的导数可以拆成多个局部导数的乘积。参数更新则把梯度转化为实际权重变化，如 `theta = theta - learning_rate * gradient`。

## 四、关键公式与符号含义
设一层计算为 `z = wx + b`，激活输出为 `a = sigma(z)`，损失为 `L`。根据链式法则，`dL/dw = dL/da * da/dz * dz/dw`。其中 `dL/da` 表示损失对激活输出的敏感程度，`da/dz` 表示激活函数的局部梯度，`dz/dw = x` 表示线性变换对权重的局部梯度。反向传播并不是重新执行模型，而是在已构建的计算图上，从损失节点向前追踪每个局部梯度。

## 五、算法流程
一次训练迭代通常包含五步：第一，把一个 batch 输入模型完成前向传播；第二，用损失函数计算预测误差；第三，清空上一轮梯度，避免梯度累加污染；第四，调用反向传播计算梯度；第五，优化器根据梯度更新参数。PyTorch 中对应的常见顺序是 `optimizer.zero_grad()`、`loss.backward()`、`optimizer.step()`。

## 六、具体例子
例子 1：若 `y = (3x + 1)^2`，当 `x=2` 时，内部变量 `u=3x+1=7`，`y=49`。链式法则给出 `dy/dx = dy/du * du/dx = 2u * 3 = 42`。这说明输出对输入的敏感程度不是凭空出现，而是由路径上每个局部梯度相乘得到。

例子 2：在二分类模型中，若预测概率离真实标签很远，交叉熵损失会较大，反向传播得到的梯度也会推动分类边界调整。若学习率过大，参数一次移动太多，损失可能震荡；若学习率过小，收敛会很慢。

## 七、PyTorch 代码示例
```python
import torch

x = torch.tensor([2.0], requires_grad=True)
y = (3 * x + 1) ** 2
y.backward()
print(x.grad)  # tensor([42.])
```
这段代码展示 autograd 自动记录计算图，并根据链式法则得到梯度。真正训练模型时，`x.grad` 通常换成模型参数的 `.grad`，优化器读取这些梯度完成参数更新。

## 八、常见误区与纠正
误区一：把反向传播理解成“把模型倒着跑一遍”。纠正：反向传播是在计算图上计算梯度，不是生成反向预测。
误区二：混淆 loss、gradient 和 update。纠正：loss 是误差数值，gradient 是误差对参数的导数，update 是优化器执行的参数变化。
误区三：忘记清空梯度。纠正：PyTorch 默认会累加梯度，因此训练循环中通常要先 `optimizer.zero_grad()`。

## 九、自测题
1. 为什么反向传播需要链式法则？参考答案：神经网络是多层复合函数，损失对前面参数的影响必须通过后续层的局部梯度逐层传回。
2. `loss.backward()` 和 `optimizer.step()` 分别做什么？参考答案：前者计算梯度，后者根据梯度更新参数。
3. 如果训练时忘记清空梯度会怎样？参考答案：梯度会跨 batch 累加，导致更新方向和幅度失真。

## 十、下一步学习建议
掌握反向传播后，可以继续学习优化算法与训练技巧，比较 SGD、Momentum 和 Adam 如何利用梯度；也可以进入 CNN 或 Transformer，观察不同结构如何共享同一套前向、损失、反向传播和参数更新框架。
