# 第 7 章 卷积神经网络 CNN

## 学习目标
- 理解卷积核、步幅、填充、通道数、池化和感受野。
- 能计算输出特征图尺寸。
- 能用 PyTorch 搭建最小 CNN 图像分类模型。

## 核心公式
输出尺寸 = `floor((输入尺寸 + 2 * padding - kernel_size) / stride) + 1`

## 直观解释
CNN 通过局部连接和参数共享提取空间特征。卷积核在输入特征图上滑动，每次关注局部区域，输出对应位置的响应值。

```mermaid
flowchart LR
  I["输入图像"] --> C["卷积层"]
  C --> P["池化层"]
  P --> F["全连接/分类头"]
  F --> O["类别预测"]
```

## 常见误区
- 忘记 padding 对左右两侧都生效。
- 只看空间尺寸，不看输入通道和输出通道。
- 把池化理解成必须步骤，忽略现代网络中的替代结构。
