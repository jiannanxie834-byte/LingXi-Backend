# 第 3 章 神经网络基础与感知机

## 学习目标
- 理解神经元的线性组合和非线性激活。
- 能画出多层感知机结构。
- 能说明隐藏层如何学习中间表示。

## 核心内容
一个神经元通常计算 `z = Wx + b`，再通过激活函数得到输出。多层感知机通过多层非线性变换表达复杂函数。

```mermaid
flowchart LR
  X["输入 x"] --> L1["线性层 Wx+b"]
  L1 --> A1["激活函数"]
  A1 --> L2["输出层"]
```

## 常见误区
- 没有激活函数时，多层线性层仍等价于单层线性变换。
- 层数、参数量和效果之间没有简单单调关系。
- 不检查输入输出维度会导致训练前就报错。
