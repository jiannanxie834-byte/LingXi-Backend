# 第 12 章 课程综合项目 章节练习题集

本题集直接服务于课程综合项目验收，覆盖 CNN 图像分类项目、数据集治理、CNN baseline、训练验证、展示报告、项目报告、评分 Rubric、复现说明、指标表、误差分析和消融实验。每题都要求学生把项目证据链写清楚，而不是只给结论。

### 题目 1：CNN 图像分类项目 的项目验收应用

**题型**：选择题  
**对应知识点**：chapter_12_final_project / CNN 图像分类项目  
**难度**：基础

**题目**：在综合项目中，哪一种做法最符合课程要求？

A. 只展示最终最高准确率，不说明数据集和训练验证过程。
B. 提供 baseline、指标表、误差分析、消融实验和复现说明。
C. 只提交截图，不提交代码和运行命令。
D. 把外部项目直接复制到报告中。

**答案**：B

**解析**：课程项目强调证据链。CNN 图像分类项目或其他主题都必须说明数据集、模型、训练验证、指标表、误差分析、消融实验和复现方式。

**常见错误**：只写“效果更好”；没有数据集说明；没有复现说明；指标表缺少对照组；误差分析没有错误样本；消融实验一次改多个变量。

### 题目 2：数据集 的项目验收应用

**题型**：判断题  
**对应知识点**：chapter_12_final_project / 数据集  
**难度**：基础

**题目**：判断并说明理由：只要 CNN baseline 的验证准确率较高，就不需要再做「数据集」相关说明。

**答案**：错误。

**解析**：综合项目不是单点评分。需要用项目报告和评分 Rubric 证明结果可复现、指标可信、错误样本经过分析，消融实验能说明每个改动的贡献。

**常见错误**：只写“效果更好”；没有数据集说明；没有复现说明；指标表缺少对照组；误差分析没有错误样本；消融实验一次改多个变量。

### 题目 3：CNN baseline 的项目验收应用

**题型**：简答题  
**对应知识点**：chapter_12_final_project / CNN baseline  
**难度**：基础

**题目**：请说明「CNN baseline」在项目报告中的位置，并写出它至少需要包含的 3 项证据。

**答案**：应包含任务定义或实验设置、可核验的日志/表格/代码证据，以及对结果的解释。例如数据集要说明来源、划分、预处理；误差分析要给错误样本、错因和改进建议。

**解析**：合格报告必须从“做了什么”走向“为什么可信”。

**常见错误**：只写“效果更好”；没有数据集说明；没有复现说明；指标表缺少对照组；误差分析没有错误样本；消融实验一次改多个变量。

### 题目 4：训练验证 的项目验收应用

**题型**：计算题  
**对应知识点**：chapter_12_final_project / 训练验证  
**难度**：基础

**题目**：某 CNN baseline 的验证准确率为 0.78，加入数据增强后为 0.82，去掉 Dropout 后为 0.75。请写出指标表中的三行记录，并说明能得出的谨慎结论。

**答案**：指标表应记录 baseline、数据增强模型、去掉 Dropout 模型及对应验证指标。谨慎结论是：数据增强可能提升泛化，Dropout 可能缓解过拟合，但仍需多随机种子和错误样本分析验证。

**解析**：计算题考查指标表和消融实验解释，不能把一次实验提升当作绝对规律。

**常见错误**：只写“效果更好”；没有数据集说明；没有复现说明；指标表缺少对照组；误差分析没有错误样本；消融实验一次改多个变量。

### 题目 5：展示报告 的项目验收应用

**题型**：代码理解题  
**对应知识点**：chapter_12_final_project / 展示报告  
**难度**：中等

**题目**：阅读项目训练伪代码，指出为了复现结果，README 至少还要补充哪些信息。

```python
python train.py --model cnn --epochs 10 --lr 0.001 --seed 42
```

**答案**：需要补充依赖安装、数据集获取方式、训练/验证划分、输出目录、模型保存文件、指标表生成方式和随机种子说明。

**解析**：复现说明不是一行命令，还要包含环境、数据、输出和评价方式。

**常见错误**：只写“效果更好”；没有数据集说明；没有复现说明；指标表缺少对照组；误差分析没有错误样本；消融实验一次改多个变量。

### 题目 6：项目报告 的项目验收应用

**对应知识点**：chapter_12_final_project / 项目报告

**解析**：实验分析题强调可核验，避免只凭报告措辞判断。

**常见错误**：只写“效果更好”；没有数据集说明；没有复现说明；指标表缺少对照组；误差分析没有错误样本；消融实验一次改多个变量。
