# 人工智能导论初始课程知识库

本目录是 LingXi 智能学习系统的初始课程知识库，满足赛题中“参赛团队需自行构造至少一门完整高校专业课程的初始知识库/文档集作为系统输入”的要求。

## 课程定位

- 课程名称：人工智能导论
- 适用对象：人工智能、计算机科学与技术、软件工程、电子信息等专业本科生
- 教学目标：帮助学生建立人工智能基本概念、算法思维、模型评估意识、多模态资源理解能力和 AI 安全意识
- 系统用途：为画像构建、资源生成、路径规划、错题诊断、资源推荐和内容安全审核提供初始课程输入

## 文档构成

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 课程元数据、知识点清单、资源文档映射 |
| `course_syllabus.md` | 课程大纲、教学目标、章节安排、评价方式 |
| `chapter_01_ai_overview.md` 至 `chapter_08_ai_safety_ethics.md` | 8 个课程章节讲义 |
| `exercise_bank.md` | 分层练习题库 |
| `practice_projects.md` | 课程实践项目任务书 |
| `learning_path.md` | 个性化学习路径模板 |

## 知识库接入方式

后端启动时会读取 `manifest.json`，将知识点写入 `course_knowledge` 表，将资源文档写入 `resources` 表并标记为“已通过”。这样学生端资源库可以直接看到初始课程资源，评价诊断也可以优先使用数据库中的课程知识点。

## 演示建议

1. 进入学生端资源库，展示“人工智能导论”相关初始资源。
2. 打开“第 7 章 多模态资源生成与智能体协同”，展示文字、流程图、题解、PPT 页纲等多模态表达。
3. 点击“导出PPT”，证明系统可以把知识库资源转为课件。
4. 在聊天中输入“我监督学习的混淆矩阵总是分不清，请帮我规划复习路线”，展示系统基于课程知识库生成资源和路径。
5. 进入管理员端资源审核页，展示生成资源的内容安全和防幻觉自检。
