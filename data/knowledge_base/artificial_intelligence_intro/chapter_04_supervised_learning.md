# 第 4 章 监督学习与模型评估

## 学习目标

- 区分分类任务和回归任务。
- 掌握混淆矩阵、准确率、精确率、召回率和 F1 值。
- 能够结合业务场景解释指标取舍。

## 核心知识

监督学习使用带标签样本训练模型。分类任务输出离散类别，回归任务输出连续数值。模型评估不能只看单一指标，特别是在类别不均衡场景中，准确率可能掩盖模型问题。

## 混淆矩阵

| 真实/预测 | 预测正类 | 预测负类 |
| --- | --- | --- |
| 真实正类 | TP | FN |
| 真实负类 | FP | TN |

- 准确率：`(TP + TN) / (TP + TN + FP + FN)`
- 精确率：`TP / (TP + FP)`
- 召回率：`TP / (TP + FN)`
- F1：精确率和召回率的调和平均

## 分层练习

### 概念判断

1. 类别极不均衡时，准确率仍然一定可靠。判断并说明理由。
2. 召回率越高，说明漏掉正类样本越少。判断并说明理由。

### 计算题

某学习预警模型结果为：TP=36，FP=12，FN=9，TN=143。

1. 计算准确率、精确率、召回率。
2. 如果学校更关注“不要漏掉真正需要帮助的学生”，应该更关注哪个指标？

### 分步题解

1. 准确率：`(36 + 143) / 200 = 0.895`
2. 精确率：`36 / (36 + 12) = 0.75`
3. 召回率：`36 / (36 + 9) = 0.80`
4. 若更怕漏掉风险学生，应优先关注召回率。

设计一个“学生学习风险预警”的监督学习任务，说明标签如何定义、特征来自哪里、应该使用哪些指标评价模型。
